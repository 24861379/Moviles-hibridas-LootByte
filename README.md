# LootByte 🎮

LootByte es una aplicación móvil híbrida orientada al comercio electrónico, enfocada en la venta de periféricos gamer como teclados, mouse, audífonos, micrófonos y otros accesorios tecnológicos. El aplicativo permite la gestión tanto para clientes como administradores, ofreciendo una experiencia de compra intuitiva y una administración centralizada del sistema.

## Instalación y ejecución ⚙️

### 1. Clonar repositorio
```bash
git clone https://github.com/24861379/Moviles-hibridas-LootByte.git
```

### 2. Ingresar a la carpeta del proyecto
```bash
cd Moviles-hibridas-LootByte
```

### 3. Instalar dependencias
```bash
npm install
```

### 4. Ejecutar la aplicación
```bash
npx expo start
```

### 5. Opciones de ejecución
- Presionar `w` para abrir en navegador
- Presionar `a` para abrir en emulador Android
- Escanear código QR con Expo Go en dispositivo móvil

## Diseño del sistema 🎨

La aplicación fue diseñada con una interfaz moderna enfocada en el público gamer, utilizando colores morados representativos de la identidad visual del proyecto, navegación intuitiva mediante barras inferiores y componentes reutilizables para mantener consistencia en toda la experiencia del usuario.
