# LootByte 🎮

LootByte es una aplicación móvil híbrida orientada al comercio electrónico, enfocada en la venta de periféricos gamer como teclados, mouse, audífonos, micrófonos y otros accesorios tecnológicos. El aplicativo permite la gestión tanto para clientes como administradores, ofreciendo una experiencia de compra intuitiva y una administración centralizada del sistema.

## Funcionalidades principales 📱

### Cliente
- Visualización del catálogo de productos
- Navegación entre productos destacados y ofertas
- Registro de usuarios
- Inicio de sesión
- Perfil de usuario
- Gestión de información personal
- Configuración de seguridad:
  - Cambio de contraseña
  - Verificación en dos pasos
  - Alertas de seguridad
- Configuración de privacidad:
  - Gestión de cookies
  - Cancelación de cuenta
- Cierre de sesión
- Carrito de compras

### Administrador
- Inicio de sesión administrativo
- Perfil del administrador
- Gestión de productos
- Gestión de usuarios
- Gestión de pedidos
- Visualización de detalles de pedidos
- Cambio de estado de pedidos
- Cierre de sesión
